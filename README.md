# Espelha-TV

Transmissão da tela de um PC para o navegador de uma TV Smart, em rede local fechada.

- Servidor em **Java 21** (sem dependências de runtime além do JDK).
- Cliente web (HTML/CSS/JS) aberto no navegador da TV.
- Vídeo por **MJPEG** (máxima compatibilidade) e controle opcional de mouse/teclado.
- Modo **espectador** por padrão; controle com trava de um único controlador.

> Documentação completa em `docs/`. Status: em desenvolvimento.
